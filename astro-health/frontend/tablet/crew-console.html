Vitalis. Crew console — retired

This design study is retired. It displayed scripted demo crew (hard-coded readings and advisory text) and, when a backend was reachable, mixed that script with live records. Nothing on it could be trusted as current, so it no longer renders.

Use the crew health monitor instead: it shows only what the backend decided, labels every reading's source, and shows nothing at all when there is no link.

The retired page is preserved in git history (frontend/tablet/crew-console.html before November 2026).
